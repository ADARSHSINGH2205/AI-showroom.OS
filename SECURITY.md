# Security Policy

AI Showroom OS contains private business, customer, supplier, inventory, and financial data. Do not open a public issue containing credentials, customer records, invoices, database files, or exploit details.

## Reporting a vulnerability

Report vulnerabilities privately to the repository owner through GitHub Private Vulnerability Reporting. Include the affected endpoint or file, reproduction steps, impact, and any suggested mitigation.

Do not test against a production deployment without explicit written authorization. Do not access, modify, retain, or disclose real business data.

## Supported version

Only the current main branch is supported until formal releases begin. Security fixes should be applied promptly and deployed after tests and backups complete.
